# 🛒 Grocery Store Website

A responsive grocery store website built with HTML, CSS, and JavaScript, featuring a dynamic product slider for an enhanced browsing experience.

## 📌 Overview
This project is a front-end grocery store website designed to showcase products in a clean, user-friendly layout. It is fully responsive, adapting smoothly across desktop, tablet, and mobile screens.

## ✨ Features
- Fully responsive design (mobile, tablet, desktop)
- Product image slider using Slick Slider (JavaScript)
- Clean and modern UI/UX
- Organized sections (e.g. Home, Products, Categories, Contact — adjust to match your site)

## 🛠️ Tech Stack
- **HTML5** – structure and content
- **CSS3** – styling and responsiveness
- **JavaScript** – Slick Slider functionality
